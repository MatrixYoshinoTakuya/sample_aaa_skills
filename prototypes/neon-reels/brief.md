# Game Brief: Neon Reels

## In your words
作成するのはスロットゲームです。
1. 企画案: クラシック3リール
2. Look: ネオンカジノ風
3. 勝敗: 終わりなし（勝ち条件なし。0枚で終了し、最高所持コイン数を記録として残す）
4. 範囲: 通しで遊べる一区切り

**Pitch:** ネオンが灯る筐体でコインを賭けて3リールを回し、ワイルドとフリースピンで最高所持コイン記録を伸ばしていくクラシックスロット。

**Genre:** スロットマシン（運試し） *(合致するジャンルシートなし。代表的な3リール機の遊び方を基準にした)*

**Controls:** スペースキーまたはSPINボタンでスピン、↑↓キーまたは＋−ボタンでベット変更、Rキーでやり直し。マウス/タッチ操作可。 *(guessed)*

**Question:** 終わりのないスロットで、ベット額の上げ下げだけで「あと1回」が続くか。 *(guessed)*

**Hooks:** ベット額を自分で上げ下げする駆け引きと、フリースピン中の配当2倍。 *(guessed)*

**Intent:** no goal to reach *(you said)*

## Look and references
- Look: 濃紺〜黒の背景に、金色の縁取りの筐体と発光する図柄。シアン=通常図柄の発光、マゼンタ=ワイルド/フリースピン、金=配当とコイン、赤=7。影は寒色、光は暖色。図柄は丸みのある太い輪郭で描き分ける（チェリー、レモン、ベル、BAR、ダイヤ、7、ワイルドの星、スキャッターの王冠）。当たりラインはネオン管が点灯する。Signature: 筐体上部のネオン管看板が当たりの大きさに応じて明滅する。every figure drawn, no emoji, no plain circles. *(guessed: 詳細)*
- References: なし
- View: 2D · Camera: 筐体正面の固定画面。 *(guessed)*

## First minute
100コインを持って筐体の前に立つ。SPINが脈動して誘い、スペースで3リールが回り左から順に止まる。最初の数回で小役が揃い、点灯したラインとコインの加算で配当の読み方が分かる。ベットを上げると払い出し表の数字が連動して増える。1分以内に王冠が3つ出てフリースピンに入り、配当2倍でコインが跳ねる。

## Challenge
払い戻し率は約94%で、回し続ければ所持コインは減る。30〜60スピン目あたりで最初の落ち込みが来る。ベットを上げれば記録は伸びやすいが尽きるのも早い。最低ベットを払えなくなれば終了で、100コインからやり直し（最高記録は残る）。 *(guessed: 数値)*

## Core loop
- ベット額を決めてスピンする → コインが減る
- 5本のラインで図柄が揃う → 配当でコインが増える、王冠3つでフリースピン
- 所持コインが最高記録を超える → 記録更新、さらにベットを上げるか決める
- コインが尽きる → 結果表示、100コインから再開

## Goal & fail state
- 最高所持コイン数の記録を伸ばす（勝ち条件なし）。
- 最低ベットを払えなくなったら終了。最高記録はブラウザに保存される。

## Features
- [ ] 3リール×3段、5ライン（横3本・斜め2本）のスピンと左から順の停止
- [ ] 図柄8種と払い出し表（ベット連動表示）
- [ ] ワイルド図柄（他の図柄の代わりになる）
- [ ] 王冠3つでフリースピン8回、配当2倍
- [ ] ベット変更（1/2/5/10コイン×5ライン）
- [ ] 所持コイン・最高記録の表示と保存、コイン切れの結果画面とやり直し
- [ ] 当たり演出（ライン点灯、コイン、看板の明滅）と合成音の効果音

## Avoid

2. 当たり演出と効果音の磨き込み。
